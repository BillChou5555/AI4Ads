# 产品需求文档 (PRD)：单列 AI 智能广告信息流 App

## 1. 产品概述

本产品是一款主打“极速体验”与“AI 内容理解”的单列广告信息流 App。通过端侧极致的资源复用与多媒体性能优化，结合服务端的自然语言搜索与大模型内容解析，为用户提供丝滑的广告浏览与智能检索体验。

* **核心价值**：打破传统广告硬广形式，利用 AI 摘要与标签提升内容的浏览效率；通过本地标签过滤与自然语言检索，降低用户的检索与筛选门槛。

## 2. 核心业务与数据流向

1. **广告物料入库**：广告商通过**物料入库接口**上传原生广告数据（含图文、音视频url等）。
2. **AI 异步预处理**：物料入库后，服务端后台异步触发大模型，完成广告摘要生成与智能标签提取，并将处理后的结构化数据落盘。
3. **信息流分发**：客户端通过 API 向服务端拉取已排序的广告流，按需渲染卡片（大图/小图/视频）。
4. **用户交互与本地过滤**：用户在单列信息流中浏览、点赞、收藏、转发、点击进入详情页，其中点赞、收藏和转发仅模拟UI效果，无需有实际功能。点击卡片标签时，客户端执行**本地数据流过滤**。
5. **对话式搜索流**：用户输入自然语言 -> 服务端进行意图识别与大模型解析 -> 返回匹配的广告列表。

## 3. 客户端需求细节 (Client-Side)

### 3.1 页面交互与布局

* **核心布局**：单列全屏信息流，支持流畅的上下滑动体验，支持下拉刷新（拉取最新推荐）与上拉加载更多。
* **顶部导航栏 (Tab)**：
* 包含预设频道（如：精选、电商、本地）。
* **交互逻辑**：支持**点击**切换和**左右滑动**切换两种方式。切换 Tab 时触发全局数据刷新，列表数据展示顺序严格依赖服务端返回的排序结果，客户端不做本地重排。
* *注：滑动切换 Tab 需配合 ViewPager2 或类似容器，确保滑动动画流畅且与点击切换的状态同步。*


* **卡片样式**：支持多态展示，包括单张大图、多张小图、视频卡片。卡片上需展示服务端下发的 **AI 摘要（副标题）** 与 **智能标签**。
* **详情页跳转**：点击卡片任意非交互区进入详情页（图文/视频详情）。从详情页返回主 feed 流时，必须**保持原页面滚动位置与状态**。
* **详情页返回手势**：支持在详情页内**向左滑动**返回主页（类似 iOS 导航返回手势），提升单手操作体验。
* **详情页媒体浏览**：当广告包含多个图像或视频时，详情页支持在媒体区域**左滑/右滑**切换浏览。媒体区域下方显示**小圆点指示器**，当前浏览的媒体对应圆点高亮。详情页浏览视频时，支持点击媒体区域暂停/播放，拖动进度条，调整音量。
* **标签本地过滤（新变更）**：
* **交互逻辑**：点击卡片上的某个智能标签（如“运动”）。
* **动作行为**：不触发页面跳转，也不请求后端接口。客户端直接在当前已加载的 feed 流数据中进行**本地高阶过滤**，立刻隐藏不符合该标签的卡片，仅显示当前 feed 流中剩余符合该标签的部分。
* *注：需支持取消过滤机制（如再次点击该标签或点击“清除筛选”），以恢复当前 feed 流的完整显示。*



### 3.2 视频与多媒体播放规则

* **自动播放/暂停边界**：以屏幕 Y 轴中心点为基准，向上延伸 **25%** 与向下延伸 **25%** 的区域划定为“核心播放区”。
* 当视频卡片主体滑动进入该区域时，自动触发静音播放。
* 当视频卡片滑出该区域时，自动暂停播放。



### 3.3 性能与资源复用

* **外流 Cell 复用**：基于列表滚动机制，对划出屏幕的卡片视图 (Cell) 进行回收重置，并提供给新进入屏幕的数据复用，避免频繁创建销毁带来的内存抖动。
* **播放器资源复用**：全局维护少量的实例化播放器内核，在信息流滚动时，仅切换播放器的 View 挂载点与视频源 URL，杜绝多实例共存导致的 OOM（内存溢出）。
* **多级缓存池设计**：
* 图片/视频首帧采用内存 + 磁盘双级缓存，保证首屏可视区域的资源优先加载。
* 建立失败重试机制与网络状态降级策略。
* **提前渲染机制**：列表在当前页面时，提前渲染上一页和下一页的内容作为缓存，当用户滑动时能够及时响应。

## 数据埋点统计
| 行为事件 | 触发条件 | 核心维度 |
| --- | --- | --- |
| **曝光 (Impression)** | 广告卡片进入客户端主界面的可视区域即上报。 | 设备 ID、广告 ID、当前所在 Tab |
| **点击 (Click)** | 用户点击卡片进入详情页。 | 设备 ID、广告 ID、触发位置 |
| **点赞 (Like)** | 用户在卡片或详情页点击点赞按钮（本地持久化状态，防重复，仅模拟，无需有实际功能）。 | 设备 ID、广告 ID |
| **收藏** | 用户在卡片或详情页点收藏层按钮（本地持久化状态，防重复，仅模拟，无需有实际功能）。 | 设备 ID、广告 ID |
| **转发** | 用户在卡片或详情页点击转发按钮（本地持久化状态，防重复，仅模拟，无需有实际功能）。 | 设备 ID、广告 ID |
| **标签过滤 (Tag_Filter)** | 用户在前端点击智能标签触发本地过滤。 | 设备 ID、标签名称、广告 ID |
